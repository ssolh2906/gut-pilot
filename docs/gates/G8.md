# G8 — Significance settings

> Set once, on the Alpha page — the first screen with a p-value on it — because these govern
> Alpha, Beta and Differential together, and stay editable from the context strip.

## 1. Anchor

`#gateStats` · Alpha page · `renderStats()`, `adjustedP()` (`#alphaOpts`, `#corrOpts`, `#statsNote`). Also reachable from `#ctxAlpha`/`#ctxBeta`/`#ctxDa` via `[data-goto-stats]`.

## 2. Layer

| Field | Layer | Note |
|---|---|---|
| `n_tested`, `significant_count`, `q_values` | Compute | BH / Bonferroni arithmetic |
| `recommendation` | Reasoning | "RECOMMENDS 0.05 WITH BH" |
| `note`, method descriptions | Evidence (T17) | |

## 3. Endpoint

`GET/POST /api/session/{sid}/stats/significance` — `{ "alpha": 0.05, "correction": "bh" }`

## 4. Request

Depends on: **G4** (feature count) and **G10** (prevalence filter) — together they set the number of tests. Circular in the mock; spec breaks the cycle by making `n_tested` a shared Compute output neither gate owns.

## 5. Response

```json
{
  "gate_id": "G8", "alpha": 0.05, "correction": "bh",
  "recommendation": { "alpha": 0.05, "correction": "bh", "label": "RECOMMENDS 0.05 WITH BH" },
  "alpha_options": [ { "value": 0.01, "label": "Strict" }, { "value": 0.05, "label": "Convention", "default": true }, { "value": 0.10, "label": "Exploratory" } ],
  "correction_options": [
    { "option_id": "bh", "label": "Benjamini-Hochberg", "controls": "FDR", "ref_key": "benjamini1995", "default": true },
    { "option_id": "bonferroni", "label": "Bonferroni", "controls": "FWER" },
    { "option_id": "none", "label": "None", "controls": null }
  ],
  "result": { "n_tested": 160, "n_significant": 5, "expected_false_positives": null },
  "note": { "severity": "info", "message": "At alpha = 0.05 with Benjamini-Hochberg, 5 of the 160 tested features reach significance." },
  "uncorrected_families": [ { "family": "alpha_diversity_metrics", "n_tests": 5, "message": "The five alpha diversity metrics are themselves five tests, and I am not correcting across them." } ]
}
```

With `correction: "none"`, `note.severity` becomes `warn` and `expected_false_positives` is populated (`n_tested × alpha`, rounded). **`uncorrected_families[]` is the gate's most honest field** — the agent volunteers what it is *not* correcting for.

## 6. Invalidation

`alpha.tests` (significance marks), `beta.permanova` (p colour threshold), `da.volcano` (q line and axis label), `da.known_taxa` (CONFIRMED/EXPECTED/MISSING flip). Cheap — only re-thresholding.

## 7. Evidence

**T17** Correction methods — not built.

| Method | Controls | Use when | Source |
|---|---|---|---|
| Benjamini-Hochberg | FDR | output is a candidate list | benjamini1995 |
| Bonferroni | FWER | a single confirmatory claim | — |
| None | nothing | never, for a screen this wide | — |

## 8. States

| Condition | Behaviour |
|---|---|
| `correction = none` | Note `warn`, reports `expected_false_positives` |
| `correction = bonferroni` | Note flags it as conservative for exploratory microbiome work |
| G1 = single-cohort | Gate still shown for reproducibility; `n_significant` null |
| `n_tested = 0` | Block rather than dividing by zero |

## 9. Decision log

Recorded **on click**, keyed `g8`, replaced in place. Both controls write one entry.

```json
{ "gate_id": "G8", "actor": "human", "decision": "Significance settings: alpha = 0.05 with Benjamini-Hochberg.", "source": "human-in-the-loop" }
```
