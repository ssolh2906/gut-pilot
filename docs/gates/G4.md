# G4 — Taxonomic rank

> Higher ranks merge taxa: statistical power up, resolution down. Changing the rank visibly
> *merges* stacked bars rather than relabelling them, so the cost of the trade is shown.

## 1. Anchor

`#gateRank` · Design page · `renderRank()` (`#rankOpts` with feature counts, `#rankNote`)

## 2. Layer

| Field | Layer | Note |
|---|---|---|
| `ranks[].feature_count`, `merge_map` | Compute | Aggregation over lineage strings |
| `recommendation` | Reasoning | "RECOMMENDS GENUS" |
| `rationale`, lineage | Evidence (T7, T8) | Why genus, and the reference lineage |

## 3. Endpoint

`GET/POST /api/session/{sid}/design/rank` — `{ "rank": "phylum" | "family" | "genus" }`

## 4. Request

Depends on: upload (lineage column). Independent of G1–G3.

## 5. Response

```json
{
  "gate_id": "G4", "rank": "genus",
  "ranks": [
    { "rank": "phylum", "label": "Phylum", "feature_count": 14,  "available": true },
    { "rank": "family", "label": "Family", "feature_count": 94,  "available": true },
    { "rank": "genus",  "label": "Genus",  "feature_count": 187, "available": true, "default": true }
  ],
  "recommendation": { "rank": "genus", "rationale": "Genus is the finest rank this table supports reliably and it is where the CRC literature reports its markers.", "citations": [{ "ref_key": "thomas2019", "doi": "10.1038/s41591-019-0405-7" }] },
  "merge_preview": { "categories_before": 9, "categories_after": 9, "merged_groups": [] },
  "warning": null
}
```

At `rank: "phylum"`, `merge_preview.merged_groups` names which genera collapse into which phylum (e.g. Faecalibacterium/Parvimonas/Roseburia/Blautia/Ruminococcus → Firmicutes), and `warning` fires: *"5 of the top composition categories merge at this rank... you gain power from fewer tests and lose the ability to name a marker."* **`merge_preview` is the gate's real payload** — naming which genera disappear is what makes the trade visible, not the feature count alone.

## 6. Invalidation

`composition` (bars merge), `da.volcano`/`da.known_taxa` (relabelled to merged name), `feature_count` → **G8** (correction denominator, so every q changes).

**Spec deviation from the mock:** the mock leaves alpha/beta untouched on rank change (precomputed per sample). In a real run rank affects the abundance matrix, so both *must* recompute — the mock's shortcut must not be ported.

## 7. Evidence

**T7** Rank-level marker reporting (which rank the CRC literature reports markers at) and **T8** Taxonomy lineage (genus → family → phylum, with DB name and version). Both not built. T8 is not optional decoration — the mock hardcodes a 9-entry lineage map; a real run needs the reference taxonomy with its version, or the merge is unreproducible.

## 8. States

| Condition | Behaviour |
|---|---|
| Lineage truncated above genus | Mark deeper ranks `available: false` with a reason |
| `rank = phylum` | `warning.severity: "warn"` |
| Species rank present | Not offered — 16S rarely resolves species reliably |

## 9. Decision log

Recorded on **Confirm design and continue**, keyed `g4`.

```json
{ "gate_id": "G4", "actor": "human", "decision": "Analysis rank set to Genus, 187 features.", "source": "human-in-the-loop" }
```
