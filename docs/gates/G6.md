# G6 — Normalization strategy

> The literature genuinely splits here, so this page argues both sides before you pick.
> Everything downstream inherits the choice. Controls G7 (existence) and G9 (validity).

## 1. Anchor

`#gateNorm` · Normalize page · `renderNorm()` (`#normOpts`, `#normNote`, `.debate-box`)

## 2. Layer

| Field | Layer | Note |
|---|---|---|
| `retention_preview` | Compute | Samples surviving under each strategy |
| `recommendation` | Reasoning | "RECOMMENDS RAREFACTION" |
| `positions[]` | Evidence (T13) | The three-sided debate is a table, verbatim |
| `constraints` | Evidence (T12, T16) | Which metrics each transform permits |

## 3. Endpoint

`GET/POST /api/session/{sid}/normalize/strategy` — `{ "strategy": "rarefy" | "css" | "clr" }`

## 4. Request

Depends on: **G5** (flagged samples quoted in the CSS note), **G1** (retention by group).

## 5. Response

```json
{
  "gate_id": "G6", "strategy": "rarefy",
  "recommendation": { "strategy": "rarefy", "label": "RECOMMENDS RAREFACTION" },
  "options": [
    { "option_id": "rarefy", "label": "Rarefaction", "summary": "Repeated subsampling to a common depth. Discards reads and excludes shallow samples.", "retention_preview": { "retained": 22, "total": 24, "excluded": ["H-09","C-04"] }, "enables_gate": "G7", "permitted_beta_metrics": ["bray","jaccard"], "default": true },
    { "option_id": "css", "label": "CSS scaling", "summary": "Cumulative sum scaling. Keeps every sample, assumes a shared scaling regime.", "retention_preview": { "retained": 24, "total": 24, "excluded": [] }, "permitted_beta_metrics": ["bray","jaccard"] },
```

On `POST { "strategy": "clr" }`, `cascades[]` reports what the choice forced:

```json
{ "cascades": [
  { "rule": "R3", "target_gate": "G7", "action": "disable", "message": "All 24 samples are retained and counts become log-ratios, so the depth threshold no longer applies." },
  { "rule": "R2", "target_gate": "G9", "action": "force", "from": "bray", "to": "aitchison", "message": "Bray-Curtis is no longer interpretable on transformed values. Moved the beta metric recommendation to Aitchison." }
] }
```

**`cascades[]` is the important field.** The mock silently mutates the beta metric inside `renderNorm()` — a silent mutation of another gate's state is the bug class this spec exists to prevent. The server must report what it changed, and the decision log must show it.

## 6. Invalidation

**Full.** Changing strategy changes the retained sample set, so alpha, beta and DA all die. `retention` (rarefy excludes by depth; css/clr retain everything), **G7** (enabled ↔ disabled, R3), **G9** (forced to `aitchison` under CLR, back to `bray` on leaving CLR, R2).

## 7. Evidence

**T12** Normalization methods, **T13** Position table (shared with G7), **T16** Transform × metric compatibility (shared with G9 and artifact rule P9). All not built.

## 8. States

| Condition | Behaviour |
|---|---|
| `strategy = rarefy` | Note `info`. G7 panel, curves and slider visible |
| `strategy = css` | Note `warn` — names the consequence: shallow samples flagged at G5 are now analysed |
| `strategy = clr` | Note `warn`. G7 hidden, G9 forced, zero-replacement rule required |
| CLR with no zero-replacement rule | Blocking — CLR on a matrix with zeros is undefined |

## 9. Decision log

Recorded **immediately on option click**, keyed `g6` — unlike Design gates, which batch on Confirm.

```json
{ "gate_id": "G6", "actor": "human", "decision": "Normalization strategy set to CLR transform, so no sample is excluded by depth and all 24 are analysed.", "source": "human-in-the-loop" }
```

Each `cascades[]` entry also produces its own log line, attributed to the agent.
