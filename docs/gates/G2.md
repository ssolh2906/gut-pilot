# G2 — Batch confounding

> Batch that tracks group membership is the most common way a disease signal turns out to be a processing signal. The agent can measure the imbalance but not whether batches were processed differently, so the decision is handed to the reviewer.

## 1. Anchor

`#gateBatch` · Design page · `renderBatch()` (`#batchTab`, `#batchNote`, `#batchOpts`)

## 2. Layer

| Field | Layer | Note |
|---|---|---|
| `crosstab`, `statistics.*` | Compute | Pure aggregation |
| `fired_rules[]`, `message`, `options[].effect` | Evidence (T4) | Table lookup, not an LLM call |
| — | **No Reasoning** | Same data must always raise the same warning |

## 3. Endpoint

`GET/POST /api/session/{sid}/design/batch` — `{ "handling": "covariate" | "stratify" | "none" }`

## 4. Request

Depends on **G1**; inactive when single-cohort (§8). Requires a `batch` metadata column; absent → gate not rendered.

## 5. Response

```json
{
  "gate_id": "G2", "covariate": "batch",
  "crosstab": { "levels": ["B1", "B2"], "groups": ["Healthy", "CRC"], "cells": [[10, 2], [2, 10]],
    "totals": { "by_level": [12, 12], "by_group": [12, 12], "n": 24 } },
  "statistics": { "group_share_in_largest_level": 0.833, "level_purity": [0.833, 0.833],
    "cramers_v": 0.667, "fisher_exact_p": 0.0004, "min_cell_count": 2 },
  "fired_rules": [
    { "rule_id": "CF-01", "severity": "warn", "message": "batch is not balanced across groups. 83% of CRC samples sit in a single batch level (B2). ...", "evidence": { "basis": "heuristic", "needs_citation": true } },
    { "rule_id": "CF-06", "severity": "info", "message": "The smallest batch x group cell holds 2 samples, so the tests above are underpowered.", "evidence": { "basis": "statistical_convention", "source_ref": "leek2010" } }
  ],
  "cleared": [ { "rule_id": "CF-02", "reason": "No level is exclusive to one group" } ],
  "highest_severity": "warn",
  "options": [
    { "option_id": "covariate", "label": "Include batch as a covariate", "effect": "PERMANOVA models batch alongside group.", "available": true },
    { "option_id": "stratify", "label": "Stratify permutations by batch", "effect": "Permutes within batch only.", "available": true },
    { "option_id": "none", "label": "Proceed and record the risk", "effect": "Results carry a confounding caveat.", "available": true, "default": true }
  ]
}
```

## 6. Invalidation

`beta.permanova` (model changes under `covariate`, permutation scheme under `stratify`), `summary.caveats` (R5). Alpha and DA unaffected. Cheap gate.

## 7. Evidence

**T4** `confounding-thresholds.json` — CF-01…CF-06, statistics, message templates, remediation. **Built.**

| Rule | Statistic | Fires | Severity | Basis |
|---|---|---|---|---|
| CF-01 | group share in largest level | > 0.70 | warn | heuristic, **uncited** |
| CF-02 | group share in largest level | ≥ 1.00 | critical | literature |
| CF-03 | level purity | > 0.75 | info | heuristic, **uncited** |
| CF-04 | Cramér's V | ≥ 0.50 | warn | convention |
| CF-05 | Fisher exact p | < 0.05 | warn | convention |
| CF-06 | min cell count | < 3 | info | convention |

## 8. States

| Condition | Behaviour |
|---|---|
| G1 = single-cohort | `active: false`, "nothing for batch to confound" |
| No `batch` column | Gate not rendered. Return `204`. |
| `fired_rules: []` | Render CF-01's clear template — good news is stated, not left blank |
| CF-02 fires | `covariate` becomes `available: false` — adjusting for complete confounding is not a fix |

## 9. Decision log

Recorded on **Confirm design and continue**, keyed `g2`.

```json
{ "gate_id": "G2", "actor": "human", "decision": "Batch handling set to proceed and record the confounding risk.", "source": "human-in-the-loop" }
```

**R5:** if `highest_severity` was `warn`+ and the reviewer chose `none`, the entry carries `caveat: true`, rendered on every PERMANOVA result and Summary.
