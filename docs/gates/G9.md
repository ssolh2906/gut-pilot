# G9 — Distance metric

> Each metric asks a different question of the same table, so this is a scientific choice rather
> than a default.

Constrained from above by G6: the CLR transform makes Bray-Curtis meaningless, so the gate is not
freely settable in every state.

---

## 1. Anchor

`#gateBeta` · Beta page · `renderBeta()`, `updatePermanova()`

Sub-elements: `#betaOpts` (four options, one disabled), `#betaNote`, `#betaConf`,
`#pcoaChart`, `.pv-strip` (PERMANOVA readout), `#heatChart`.

## 2. Layer

| Field | Layer | Note |
|---|---|---|
| `pcoa`, `permanova`, `matrix` | Compute | |
| `recommendation`, `confidence` | Reasoning | 81% for Bray-Curtis, "REVIEWER OVERRIDE" otherwise |
| `options[].rationale`, `availability` | Evidence (T21, T22, T16) | |
| `interpretation` | Evidence (T23) | Effect-size bands, not a generated sentence |

## 3. Endpoint

`GET  /api/session/{sid}/beta/metric`
`POST /api/session/{sid}/beta/metric` — `{ "metric": "bray" | "jaccard" | "aitchison" }`
`GET  /api/session/{sid}/beta/ordination` · `GET .../beta/matrix`

## 4. Request

Depends on: **G6** (permitted metrics, R2), **G7** (retained samples), **G3** (permutation scheme),
**G2** (whether batch enters the model), **G8** (p-value threshold colouring).

The most upstream-dependent gate in the system.

## 6. Invalidation

| Target | Effect |
|---|---|
| `beta.pcoa` | new ordination |
| `beta.matrix` | new distances |
| `beta.permanova` | new R², p |

Medium — distances recompute, but rarefaction does not. Alpha and DA are untouched.

## 7. Evidence

| Table | Supplies | Status |
|---|---|---|
| **T21** Distance metrics | required input, abundance weighting, valid transforms | Not built |
| **T22** Metric availability rules | gate conditions and messages | Not built |
| **T23** Effect-size interpretation | R² bands, permutation defaults, sparsity cutoff | Not built |
| **T16** Transform × metric compatibility | shared with G6 and artifact P9 | Not built |

T23 must define the `effect_band` thresholds. "Tiny R²" is currently a judgement rendered as prose;
banding it (`small` < 0.05, etc.) makes it checkable and consistent between the caption, the AI dock
and the Summary.

## 8. States

| Condition | Behaviour |
|---|---|
| G6 = CLR, metric ≠ aitchison | **R2.** Note is `warn`: "Metric does not match the transform… Switch to Aitchison, or change the normalization back." Mock auto-corrects; see Deviations |
| G6 ≠ CLR | `aitchison` unavailable with reason |
| No tree supplied | `unifrac` unavailable with reason. Never silently omitted from the list — a missing option is invisible, a disabled one is informative |
| G1 = single-cohort | PERMANOVA strip replaced by `cohortBlocked()` note. PCoA and distance matrix still render — they are descriptive |
| Metric ≠ recommendation | `confidence_label` becomes "REVIEWER OVERRIDE" rather than a percentage |

## 10. Open

1. `dispersion_p` is missing from the mock. Needed before the "not significant" claim can be made.
2. PC1 34.7% / PC2 11.2% are hardcoded literals in `drawPcoa()`. Must come from the eigenvalues.
3. Sparsity 38% is a literal used to justify skipping a tree-aware metric. Compute it, and put the
   decision threshold in T23.
4. Where does a phylogenetic tree get uploaded? It only unlocks UniFrac here, so it has no home in
   the flow. (Carried from the flow spec.)
5. Does `strata` come from G3 (subject) or G2 (batch stratification), and what happens when both
   apply? Undefined.

## Deviations from the mock

- **Mock auto-corrects instead of warning.** `renderNorm()` forces `betaMetric = "aitchison"` when
  CLR is chosen, so the R2 warning branch in `renderBeta()` is unreachable in normal use. Spec keeps
  the forcing (as a reported cascade, per G6) *and* keeps the warning reachable for the case where
  the metric is set first and normalization changes after.
- `BETA_INFO` stores fixed R²/p per metric. Real values come from the permutation test.
- Mock's PERMANOVA model ignores G2 entirely — choosing "include batch as a covariate" changes no
  number. Spec requires `model` and `strata` to reflect G2 and G3.
