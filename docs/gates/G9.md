# G9 — Distance metric

> Each metric asks a different question of the same table, so this is a scientific choice
> rather than a default. Constrained from above by G6: the CLR transform makes Bray-Curtis
> meaningless, so the gate is not freely settable in every state.

## 1. Anchor

`#gateBeta` · Beta page · `renderBeta()`, `updatePermanova()` (`#betaOpts` four, one disabled · `#betaNote` · `#betaConf` · `#pcoaChart` · `.pv-strip` · `#heatChart`)

## 2. Layer

| Field | Layer | Note |
|---|---|---|
| `pcoa`, `permanova`, `matrix` | Compute | |
| `recommendation`, `confidence` | Reasoning | 81% for Bray-Curtis, "REVIEWER OVERRIDE" otherwise |
| `options[].rationale`, `availability` | Evidence (T21, T22, T16) | |
| `interpretation` | Evidence (T23) | Effect-size bands, not a generated sentence |

## 3. Endpoint

`GET/POST /api/session/{sid}/beta/metric` — `{ "metric": "bray" | "jaccard" | "aitchison" }`. Also `GET .../beta/ordination` · `GET .../beta/matrix`

## 4. Request

Depends on: **G6** (permitted metrics, R2), **G7** (retained samples), **G3** (permutation scheme), **G2** (batch in the model), **G8** (p colouring). Most upstream-dependent gate.

## 6. Invalidation

`beta.pcoa` (new ordination), `beta.matrix` (new distances), `beta.permanova` (new R², p). Medium — distances recompute, rarefaction does not. Alpha and DA untouched.

## 7. Evidence

**T21** Distance metrics, **T22** Metric availability rules, **T23** Effect-size interpretation (R² bands, permutation defaults, sparsity cutoff), **T16** Transform × metric compatibility (shared with G6 and artifact P9). All not built. T23 must define `effect_band` thresholds (`small` < 0.05, etc.) so "tiny R²" is checkable and consistent everywhere.

## 8. States

| Condition | Behaviour |
|---|---|
| G6 = CLR, metric ≠ aitchison | **R2.** Warn: metric doesn't match the transform. Mock auto-corrects instead of warning — spec keeps the forcing as a reported cascade (G6 §9) *and* keeps this warning reachable |
| G6 ≠ CLR | `aitchison` unavailable |
| No tree supplied | `unifrac` unavailable — disabled, never silently omitted |
| G1 = single-cohort | PERMANOVA strip replaced by blocked note; PCoA and matrix still render |
| Metric ≠ recommendation | `confidence_label` becomes "REVIEWER OVERRIDE" |

## 9. Decision log

Recorded **on click**, keyed `g9`.

```json
{ "gate_id": "G9", "actor": "human", "decision": "Beta diversity metric set to Jaccard (R² = 0.052, p = 0.011).", "source": "human-in-the-loop" }
```

Entries forced by R2 (G6 → CLR) are attributed to the **agent**, referencing the cascade.
