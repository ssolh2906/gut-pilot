# G1 — Group definition

> What is being compared. Everything downstream assumes this is right.

## 1. Anchor

`#gateGroups` · Design page · `renderGroups()` (`#groupOpts`, `#groupAssign`, `#groupNote`, `#groupConf`)

## 2. Layer

| Field | Layer | Note |
|---|---|---|
| `detected_pattern`, `groups[]`, `assignment[]` | Compute | String matching over sample IDs |
| `confidence` | Reasoning | 92% in the mock, a literal — formula TBD |
| `message` | Evidence (T3) | Template, not free text |

No Claude call needed — the pattern match is deterministic.

## 3. Endpoint

`GET/POST /api/session/{sid}/design/groups`

## 4. Request

Depends on: upload only. First gate.

```json
{ "source": "inferred" | "manual" | "metadata" | "none", "assignment": { "H-01": "Healthy" } }
```

`assignment` required only when `source` is `manual`.

## 5. Response

```json
{
  "gate_id": "G1", "source": "inferred",
  "detected_pattern": { "rule_id": "IDP-01", "pattern": "^([HC])-\\d{2}$",
    "mapping": { "H": "Healthy", "C": "CRC" }, "match_rate": 1.0, "matched": 24, "total": 24 },
  "groups": [ { "label": "Healthy", "n": 12 }, { "label": "CRC", "n": 12 } ], "balance": 1.0,
  "confidence": 0.92, "confidence_basis": "pattern_match_rate_and_balance",
  "message": "Inferred two groups from the ID prefix: Healthy 12 and CRC 12. ...",
  "options": [
    { "option_id": "inferred", "label": "Use the inferred grouping", "available": true, "default": true },
    { "option_id": "manual",   "label": "Assign groups manually", "available": true },
    { "option_id": "none",     "label": "No grouping, single cohort", "available": true }
  ]
}
```

`match_rate`/`balance` ship so `confidence` is checkable, not just asserted.

## 6. Invalidation

**Everything.** | `manual` → full recompute | `none` → R4 (§8) | `inferred`↔`metadata` → recompute only if assignments differ.

## 7. Evidence

**T3** ID-pattern rules — pattern, mapping, confidence weighting, message templates. Not built;
one rule (`IDP-01`) covers the demo.

## 8. States

**`source = none` → single-cohort mode (R4), a supported mode, not a degraded one.**

| Panel | Behaviour |
|---|---|
| Alpha group tests | blocked note; per-sample alpha still computed |
| PERMANOVA / Volcano / DA | blocked note / hidden |
| Known-taxa cross-check | blocked — no second group to key a direction of change on |
| G2 | inactive: "nothing for batch to confound" |

Still available: depth, composition, per-sample alpha, distance matrix. Metadata `group` column → `source: "metadata"`, confidence 1.0, still shown for confirmation. No pattern match → fall back to `manual`. Fewer than 2 groups → same as `none`.

## 9. Decision log

Recorded on **Confirm design and continue**, keyed `g1`.

```json
{ "gate_id": "G1", "actor": "human", "decision": "Confirmed the grouping (inferred from sample ID prefix): Healthy 12 against CRC 12.", "source": "human-in-the-loop" }
```
