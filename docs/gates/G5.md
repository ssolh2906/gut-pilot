# G5 — QC depth floor

> The floor flags only. Exclusion happens at the rarefaction gate (G7) — a sample can be flagged
> here and still analysed, and when that happens, R1 fires.

## 1. Anchor

`#floorSlider` + `#floorNote` + `#floorTag` · Raw QC page · `renderFloor()`, `setFloor()`, `floorNote()` (`#floorRead`, `.floor-presets .chip`, `#depthChart`, `#qcHint`, `#checks`)

## 2. Layer

| Field | Layer | Note |
|---|---|---|
| `depth_stats`, `flagged[]`, `bars[]` | Compute | |
| `fired_rules[]`, `message` | Evidence (T9, T10) | All six advisories are table rules |
| — | **No Reasoning** | Same floor must always flag the same samples |

## 3. Endpoint

| Call | When | Cost |
|---|---|---|
| `GET .../qc/depth` | Page enter, once | medium — returns all bars |
| `GET .../qc/floor?value=` | Slider drag, debounce 150 ms | cheap, pure function |
| `POST .../qc/floor` | Slider settle / preset click | cheap, records decision |

Fetch once, evaluate cheaply during interaction, commit explicitly — same split as G7.

## 4. Request

Depends on: **G1** (bars coloured by group). Reads **G7**'s depth for R1. Slider: `min 500, max 20000, step 250`. Default `5000`.

## 5. Response

`GET .../qc/floor?value=5000`:

```json
{
  "gate_id": "G5", "floor": 5000, "is_default": true,
  "flagged": [ { "sample_id": "H-09", "group": "Healthy", "depth": 1842 }, { "sample_id": "C-04", "group": "CRC", "depth": 2116 } ],
  "flagged_summary": { "n": 2, "total": 24, "pct": 8, "by_group": { "Healthy": 1, "CRC": 1 } },
  "fired_rules": [], "cleared": ["FL-01","FL-02","FL-03","FL-04","FL-05"],
  "consistency": { "rule": "R1", "fired": false, "gap_samples": [], "message": "The floor is above the rarefaction depth of 4,200 reads, but no sample falls between them." },
  "severity": "info"
}
```

`GET .../qc/depth` (once) returns `stats`, pre-sorted `bars[]` (ascending by depth), and three `presets` (1,000 / 5,000 Weiss 2017 / 10,000).

## 6. Invalidation

`qc.flags`/`qc.checklist` (reclassification), `warnings.P1`. **Nothing statistical.** Cheapest
gate in the system — it decides nothing about the analysis, by design.

## 7. Evidence

**T9** Published depth floors, **T10** Floor advisory rules, **T11** QC check registry — all not built.

| Rule | Condition | Severity | Basis |
|---|---|---|---|
| FL-01 | ≥2 flagged, all in one group | warn | reasoned |
| FL-02 | flagged fraction > 25% | warn | **heuristic, uncited** |
| FL-03 | floor < 1,000 | warn | reasoned — richness unstable |
| FL-04 | floor > 15,000 | warn | **heuristic, uncited** |
| FL-05 | R1 gap samples exist | warn | internal consistency |
| FL-06 | flagged = 0 | info | states the clean case explicitly |

## 8. States

| Condition | Behaviour |
|---|---|
| `flagged = []` | `#floorTag` green; `#qcHint` states no sample flagged, rarefaction still decides exclusion |
| G6 ≠ Rarefaction | Floor becomes **QC annotation only** — R1 cannot fire, nothing excluded by depth |
| G1 = single-cohort | FL-01 cannot fire; report as `cleared`, not passing |

**R1.** Fires when `∃ sample: depth < floor AND depth ≥ G7.threshold`. Both fixes (raise G7's depth, lower G5's floor) are offered; either is legitimate. When numbers merely differ with no sample in the gap, say so rather than warning.

## 9. Decision log

Recorded on slider **`change`** (settle), never `input` (drag). Keyed `floor`, replaced in place, **only when it differs from the 5,000 default.**

```json
{ "gate_id": "G5", "actor": "human", "decision": "Reviewer set the QC depth floor to 8,000 reads (default 5,000). 4 of 24 samples flagged as under-sequenced.", "source": "human-in-the-loop" }
```
